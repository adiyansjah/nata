# Compaction before arrow wrappers: what the copy costs

Host: arch aarch64, cpu 0xd8e, 8 logical CPUs. Release build, overflow-checks on for this crate, off for dependencies. Data: in-cache batches, warm; compaction copies one column and allocates its output on every call.

## Compaction vs carrying the selection, NULLs 10%

25 interleaved rounds per cell (arm order rotated each round), one thread. Load average (1 min): start 0.49, highest between cells 0.57, end 0.57.

All times are ns per SELECTED row (arm time / k), median [lower quartile, upper quartile] over rounds. Ratios are paired per round: the ratio of the two arms' times from the same round, median [q1,q3]. D processes ALL n rows; its ns/row-selected is n*d/k, the cost of not selecting.
