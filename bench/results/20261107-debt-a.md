Cause: sqlparser recursive descent uses much more stack under ASan. The earlier

| recursive function | fixed local frame B | ASan local/redzone B | saved registers + return B | alignment upper bound B |
|---|---:|---:|---:|---:|
| parse_prefix | 1,376 | 10,240 | 56 | 62 |
| parse_subexpr | 352 | 3,392 | 56 | 62 |
| parse_case_expr | 448 | 4,064 | 56 | 62 |

## R17: decimal to double

Cause: `powi` does not promise an exact power of ten, including under Miri.
Fix: literal table 10^0 through 10^22, all exactly representable in binary64;
when the coefficient magnitude is at most 2^53, both operands are exact and one
IEEE division rounds the exact quotient once. Wider coefficients/scales retain
the exact decimal-text to correctly rounded Rust float parser path. No
coefficient-first rounding for the wide path.

`cargo run -p nata-exec --example decimal-bits` exposes actual conversion bits.
`python3 crates/nata-exec/decimal-oracle.py target/debug/examples/decimal-bits WORK`
compares **1,000,000 decimals**, seed **17179869189**, all **779** legal (p,s)
pairs (1 <= p <= 38, 0 <= s <= p), signs, zero and maxima against an independent
exact Python Decimal tuple construction followed by `float()`: **0 differences**.
Tuple construction avoids context-precision rounding in the oracle itself.
**Miri 15/15 PASS**, including all original 14 scalar tests and the new allocation-gauge test. Mutation results follow below. The existing scalar test for (15,1)
retains exact equality; no tolerance weakening.

## R19: exceptional dates

Cause: wire text refused every non-four-digit AD date; binary encoding used
chrono's narrower civil-year domain. Fix: validate raw Date32 days against
PostgreSQL's finite Julian range, format using proleptic Gregorian arithmetic,
and encode checked signed days since 2000-01-01. OID 1082 stays fixed in text,
binary and COPY binary; NULL remains NULL. Any Nata day outside PostgreSQL's
finite domain returns **22008**, before a value for that row is sent. No
Date32 sentinel is silently reinterpreted as wire infinity.

Real private local **PostgreSQL 17.11** oracle: exact text and byte-for-byte
binary DataRow/COPY for eight dates, including BC, year zero (1 BC), 9999/10000,
and PostgreSQL's endpoints; five invalid dates cover Date32 min/max and the
adjacent invalid PostgreSQL days. PostgreSQL's actual earliest date is
**4714-11-24 BC** (Julian 0), despite the commonly summarized 4713 BC range;
latest is **5874897-12-31**. Binary bounds since 2000 are
**[-2,451,545, 2,145,031,949)**, and the epoch offset is 10,957 days.

CLI text remains the documented DuckDB-oriented form: BC `0044-03-15 (BC)`,
large years unpadded beyond four digits; the legacy Date32 `i32::MAX` and
`-i32::MAX` spellings remain `infinity`/`-infinity`. Wire treats those as raw
out-of-range days and returns 22008. `i32::MIN` formats as a civil BC date on
the CLI and also returns 22008 on the wire. Input DATE literals/casts and
parameters remain restricted to 0001–9999; this change certifies column output.

Default clients, compared against the **same PostgreSQL queries**, with no
protocol options changed:

- psycopg **3.3.8**: native datetime.date for 0001–9999; explicit DataError
  outside that Python domain, identically on Nata and PostgreSQL. No wrong date.
- ADBC PostgreSQL **1.13.0**, pyarrow **26.0.1**: native Arrow Date32 preserves
  all eight exact signed day values and NULL. Read back through int32 to avoid
  Python datetime's smaller domain.
- pgjdbc **42.7.14** (also 42.7.7), Java **21.0.13**: ten prepared executions per date, spanning
  its default text/binary switch. `LocalDate`, default `java.sql.Date` and
  `getString` match PostgreSQL. `LocalDate` preserves the full date; default
  Date/string presentation has driver limitations (e.g. Date.toString drops
  high year digits; binary earliest date getString prints -infinity on both
  servers). These are client behavior, not an OID change or Nata conversion.
  Each invalid Date32 produces SQLSTATE 22008.

Reproduce with `tests/date_oracle.py NATA_PORT PG_PORT WORK NATA_BINARY` and
`DateDomains.java NATA_PORT PG_PORT WORK`; raw summaries in
`raw/20261107-debt-a/date-oracle.json` and `date-jdbc.txt`. Protocol tests retain
independent day-byte constants, NULL/COPY framing and SQLSTATE assertions.
Mutation results follow below.
